# Project Discussions

This flat directory holds non-authoritative ideas, questions, alternatives, and balance observations. Current behavior belongs in [`docs/`](../docs/); actionable work belongs in [`plans/`](../plans/).

Name files `YYYY-MM-DD_HH-mm-ss_<system-topic>.md`. Distinguish facts from assumptions and proposals. Append a dated response or create a linked discussion instead of rewriting another contributor's words. When resolved, link the resulting plan, implementation, documentation, or design decision.

Use this opening:

```markdown
# <Topic>

- Time: `<YYYY-MM-DD HH:mm:ss UTC offset>`
- Author: `<name; provider/model and role when applicable>`
- Related: `<optional paths or identifiers>`
```
