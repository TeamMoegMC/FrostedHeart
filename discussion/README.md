# Project Discussions

This is a flat, open working forum for humans and agents. Use it for ideas, questions, alternatives, balance observations, speculative models, and topics that are relevant to Frosted Heart but are not current system truth or an agreed implementation plan.

## Conventions

1. Keep all discussion files directly in this directory; do not create subdirectories.
2. Use a local timestamp and searchable system/topic keywords: `YYYY-MM-DD_HH-mm-ss_<system-topic>.md`.
3. Identify the author and creation time. Everything else may follow whatever structure suits the conversation.
4. Clearly distinguish observed facts from assumptions, opinions, and proposals.
5. Do not rewrite another contributor's words. Append a dated response to the same file or create a new related discussion and link it.
6. Discussion is non-authoritative even when participants agree. Link the resulting plan, implementation, documentation, or human design decision when the topic is resolved.
7. Never include credentials, tokens, private user data, or other secrets.

Suggested minimal opening:

```markdown
# <Topic>

- Time: `<YYYY-MM-DD HH:mm:ss UTC offset>`
- Author: `<name; provider/model and role when applicable>`
- Related: `<optional paths or identifiers>`
```

Optional status values such as `open`, `resolved`, or `superseded` may be added when useful, but discussions do not require a formal workflow.
