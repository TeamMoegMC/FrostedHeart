## 定位与范围

一片被严寒封住、仍有局部地热活动的地下岩洞。厚冰壁、冻结水潭、冰瀑和悬冰构成主要景观，深部零星温泉形成探索惊喜和休整机会。玩家通过观察脚下与头顶、选择路线和建立落脚点克服环境。

用户已确定：服务 TWR，视觉接近冰洞而行为适配 FH 温度；需要保暖装备；薄冰、冰锥及冰溜子由已有工作推进；新增地形只生成在新区块，允许已约定的运行时生长；深处希望有零星温泉作为水汽来源。用户接受先用局部水潭、短河床和冰瀑表达冻结水系，连续暗河不作为第一版前提。

下文具体景观、密度、光照和温泉方案均为推荐，尚非全部用户定案。不引入 Frostbite、冻结战斗、完整局部湿度、流域侵蚀或整洞路线规划。`design/` 保持只读；当前实际行为以源码和数据为准。

## 空间与生成策略

第一版沿用现有 `the_winter_rescue:ice_caves` 分布和洞穴骨架，优先在自然形成的宽阔空间组织景观。窄通道采用较轻装饰，大洞厅采用明显厚冰与局部地标；不会把所有空间加工成同一种大厅。

- 群系层：维持现有 ID；不强制“只有噪声洞穴才能是冰洞”，也不承诺雕刻器隧道不进入。
- 洞形层：首版以有限的池底、岸台与壁面修整为主，不重做全局密度。若实测合适大洞厅过少，再考虑用共享区域规则调整冰洞密度与群系分布。
- 材质层：为墙面、洞顶和地面赋予连贯的冰层与裸岩分布；根据洞穴暴露面处理，不假设普通地表规则已能覆盖所有洞壁。
- 景观层：寻找符合空间、支撑和水池容纳条件的位置，再放冰瀑、水潭、冰锥簇或温泉。失败候选跳过，避免为保证景观数量大规模改造山体。
- “深部温泉”首版解释为群系中较低的高度带、适宜的地下池盆，绝对 Y 范围待种子调查决定。不是扫描整座连通洞穴寻找唯一最低点；也不保证每洞一池。

样板中的绕行与回环用于检验体验；随机世界只要求局部景观留出合理落脚空间，不保证整个自然洞网一定可步行贯通。玩家搭桥、挖路、清理冰锥都是正常解法。

## 外观与材质

总体色彩为灰、白、浅青和少量深蓝。核心洞厅冰体明显，连接通道与侧洞多露岩；比例按局部场景调整，不用全洞固定百分比随机混铺。

| 元素 | 推荐表现 |
| --- | --- |
| 厚冰壁 | 浮冰为主体，成片覆盖并形成阶梯状厚薄变化；冰壁后保留岩体。 |
| 深蓝冰 | 少量藏在厚冰断面、裂隙和冰瀑内部；既作地标也可采集。 |
| 岩石与方解石 | 岩石形成岸边、平台、矿脉露头；方解石作局部条带和温泉沉积过渡，不遍地碎花。 |
| 地面 | 完整厚冰、裸岩台阶与局部薄冰水潭交替；薄冰不覆盖整洞，也不以雪掩盖风险。 |
| 大型冰柱 | 用完整冰方块构成，承担体量与视线分隔；不要求现有细冰锥自动长成接地粗柱。 |
| 积雪 | 入口、天窗及其附近受影响区域为主；深洞不均匀铺雪，首版不增加粉雪陷阱。 |
| 冰锥 | 在冰质洞顶或冰结核下成簇，夹杂空白区；沿用当前长度与交互机制，不扩展侧向生长。 |

裸岩平台上方初始不放冰锥；自然根部仍依赖合格冰基底，因此这种分区有长期意义。现有 `IcicleFeature` 允许石质完整底面，落地时必须同步调整初始放置条件，不能只凭自然生长规则宣称石顶没有冰锥。保留玩家手动改变顶材或放置冰锥的自由。

## 可组合景观

尺寸仅是样板候选范围，单位为方块，不是最终生成配置。

| 景观 | 形态与候选尺度 | 体验与放置约束 |
| --- | --- | --- |
| 冻结水潭 | 横向约 4–10 格、通常 1–3 格深；岸边厚冰或裸岩，中心少量薄冰 | 可沿岸绕行、搭桥或穿冰；提供容易爬出的边缘。检查池底、池岸及破冰后的出水路径。 |
| 短冻河床 | 约 8–20 格弯曲浅槽，局部冰阶、沉积石和封冻水洼 | 提供方向感和过去流水的痕迹，不要求连接远处另一条河床。 |
| 冰瀑壁 | 约 4–10 格高、3–6 格宽，依附有实际后壁的落差 | 视觉焦点，侧边可有岩台或浅凹洞；不要求每道冰瀑后都有宝箱。 |
| 高顶冰厅 | 优先选择已有约 12–24 格宽的自然空腔 | 厚冰壁、稀疏悬冰、矿脉露头或回廊视线；空间不够时不强造。 |
| 裸岩侧台 | 约 3–6 格可站立空间，头顶无初始悬冰 | 玩家整理物品、自行点火、观察路线；只是适合扎营，不自动具有温暖或无怪保障。 |
| 深部温泉 | 初试池面约 3–7 格，局部石灰岩/方解石池岸，水深便于退出 | 稀有暖点，池边保留干燥站立处，候选池之间保持间距；数量由实际分布校准。 |

每个候选空间按条件挑选适量景观，留出无特别事件的过渡区域。避免一个洞厅同时堆满薄冰、密集落冰、粉雪、熔岩和战利品。

## 温泉：景观与热学

推荐外围关系为：**泉眼和裸岩水池 → 潮湿池岸 → 外缘霜冻与悬冰 → 冰封洞道**。这是期望的空间表现，具体距离必须由热学试验确定。暖池附近初始少放容易迅速融掉的装饰，休整岩台上方不挂危险冰锥。

1. **形态复用**：现有热液矿床的石灰岩围边水池可作为原型素材，不直接把整个热液群系移植进冰洞。
2. **持续热量**：建议单个池或小片泉眼注册持续地热来源，复用现有热源框架；不让每格水都独立成为常驻热源。供热端口、功率、作用范围和存档生命周期需要专门核实，不视为已经支持。
3. **初始热状态**：指定生成初温目前无现成世界生成接入。初温解决首次出现时是否已经暖，地热解决长期维持；先验证持续供热，再判断是否必须补通用初温能力。若初次加载长期出现冷泉，不能仅靠水汽掩盖。
4. **玩家体感**：目标为合适装备玩家在岸边可以恢复，下水保留潮湿取舍。现有 `PlayerThermalModel.waterTemperatureC` 用当地气温限制到 0–35°C，并未直接读取水材料温度；必须验证岸边与入水结果，不能把水材料变热直接当作泡温泉功能完成。
5. **水汽表现**：局部低密度粒子和水声，提供方向线索；只作环境表现，不模拟整个洞穴的水汽输运。避开用全洞浓雾遮挡薄冰和冰锥预警。
6. **地形边界**：温泉允许周围有限融冰，池盆边界使用稳定岩材。热区不应消除整片冰洞的保暖需求，也不保证在任意装备、任意寒潮下无条件安全。

不采用热液矿床 +40°C 群系加项来抬高整个冰洞温度。温泉被挖开、改造、拆除或封住后的热源行为需定案；不能在实现前承诺泉眼可搬走、无限灌热水或具有额外治疗效果。

## 光照、声音与危险

- 推荐少量可采集冰晶作为新环境元素，照出局部冰面、转角或高处目标；不让整片冰壁发光。未制作前可用临时光源验证布光，冰晶亮度以无光影试玩决定。
- 发光地衣稀疏保留，冰晶逐步承担主要视觉地标；发光鱿鱼仅提供水中亮点，不计为环境照明。
- 玩家光源揭示近处细节，自然光点提示方向。日光仅用于真正与地表连通的入口/天窗，不要求每座冰洞都有地表入口。
- 音景安静，水滴、脚步和少量环境音为主；薄冰与冰锥的预警必须清楚。首版避免二者在同一局部同时作为主要危险。
- 薄冰风险体现为落水、潮湿和失温；教学样板选能显示预警的厚度，不保证每次踩踏都推进，也不用一两层冰宣称“先裂后碎”。
- 冰锥风险通过可见尖端、冰屑与声音表达；把主落脚点、池边岩台与密集悬冰区错开。静止冰锥不当作额外刺伤陷阱。

## 资源、既有内容与回访

进入动机优先采用已有冰类建材、矿脉、探索景观和可自行建设的落脚点；暂不增加专属矿物或强制科技进度材料。矿脉保留在裸岩露头，冰壁覆盖要避免把全部矿石遮住或替换掉。矿石实际可采集收益与城镇 `biome_mine` 配方分开讨论，不将后者当作玩家挖矿掉落。

推荐减少冰洞内部随机熔岩湖/泉，让温泉成为主要暖色与热活动地标；罕见与火山/热液区域交界仍可有熔岩。水泉减少任意穿墙泄流，改以能容纳的水潭和冰瀑景观为主。矿脉先保留，怪物房与虫蚀石先评估是否干扰环境体验，再决定减量；不新增专属敌对生物。

回访来自采集、开路、搭桥、温泉前哨和装备提升。冰锥再生、薄冰回冻与玩家供热会改变局部环境，但不承诺在一次往返内完成恢复。玩家痕迹应正常保存；不会为了重置体验定期回填洞穴。

## 实施顺序与验收

1. **现状采样**：在若干固定种子中记录冰洞的高度、空腔大小、水体、可用岩台与现有冰锥密度；选出适合首版的条件，暂不强制改变群系分布。
2. **双场景样板**：制作一处高顶冰厅（冰壁、局部薄冰、冰瀑、裸岩侧台）和一处小温泉侧洞。手工样板允许连通，随机生成尚不保证同样布局。
3. **热学与通行验证**：比较寒潮/较暖时段、装备档位、岸边/入水、首次加载/重载；观察池水冻结、装饰融化、预警和脱困。持续地热是温泉上线前提，蒸汽仅为表现。
4. **局部生成接入**：分别实现材质覆盖、池盆/冰瀑与簇状装饰，检查支撑、邻区块衔接、矿脉、流体更新。生成与长期生长共用视觉分区目标。
5. **整合与平衡**：验证新区块生成时间、密集材料与坠落负载、长期冰锥密度和透明渲染，再调整数量。只有现有洞形明显限制效果时，再推进冰洞专属密度规则。

验收重点：不开光影仍可识别冰洞与风险；样板有可理解的绕行/搭桥选择；暖点确实能按目标装备改善体温，离开仍需保暖；生成不形成明显漏水、截断与大面积悬空；长期游玩不把所有落脚空间长成悬冰密林。自动测试不代替这些玩法与性能实测。

## 优先待确认

1. 哪一档现有保暖装备用于常规探索，温泉是短暂缓解还是可长期扎营？推荐装备达标后岸边可恢复，离泉仍需保暖。
2. 泉眼是什么可辨认的对象，是否可破坏/采集，是否接受玩家将温泉改造成长期据点？推荐先作为固定自然地点，不提供便携无限热源。
3. 冰晶是否纳入首版、是否可采集作照明？推荐少量可采集装饰光源，暂不绑定科技必需配方。
