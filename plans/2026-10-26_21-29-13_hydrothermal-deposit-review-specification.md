## 1. 审核对象与核心画面

本稿将此前几版讨论合成一个明确样本：**地下洞穴切露一条斜向含矿破碎带，浅色矿物胶结着深色碎块，带内有局部金属露头；矿化带继续进入水下岩体，壁脚有不对称、大小不同的池群。**

主壁是远景轮廓，池群是显著前景，含矿破碎细节和采矿反馈承担近距离识别。池群保留重要视觉地位；不把地下矿床等同于整片地表热泉阶地，也不要求玩家知道“破碎带”等术语。

采用“过去热液活动形成的脉型多金属矿化，后来被洞穴和地下水局部暴露”的艺术化解释。现在的水不因群系名称而自动成为永热水。实际热状态由已有材料和热系统决定。

这一设计只对应热液矿床的一种成矿与景观方向。其他矿床和火山可复用布局/归属/密度接线，但不共用全部形状与装饰。

## 3. 标准样本尺度

单位均为方块。这些是首个样本的尺寸意向，不是原型已验证结果。旧原型的160/64/40不继续作为单厅美术标准。

| 部位 | 标准样本 | 后续允许变化的初始范围 |
|---|---:|---:|
| 整体矿化影响包络 | 主轴176、横向80 | 主轴160..208、横向64..88 |
| 矿化与周围岩层的纵向影响 | 约48 | 按洞顶/池底加围岩余量推导，不等于空气净高 |
| 主厅 | 长68、宽36 | 长60..80、宽30..42 |
| 主厅常用净高 | 20..24 | 主要空间18..26，少数拱顶可略高 |
| 入口/连接段 | 宽6、净高9 | 宽5..9、净高7..12 |
| 较小扩宽 | 长28、宽18、净高12 | 长20..36、宽12..24、净高9..16 |
| 主矿化岩壁可见面 | 宽约40、高约20 | 宽32..48、高16..24 |
| 水池总数 | 3个，其中1个较显著 | 2..3个，支池可以不生成 |
| 池深 | 主要1..3 | 少量局部4..5，不作为必经道路 |

整体包络包含实心围岩、隐伏矿脉和支脉，不等于空腔包围盒。主厅宽高不要求在每个断面同时达到最大值。初样可见地表面积以大部分围岩/岸台、局部水面为目标，避免以挖空量或水面总量作为“大”的指标。

## 4. 标准样本平面布局

使用局部坐标u沿矿化主轴、v横向、w相对主厅常见岸面。实际世界中整体可旋转/镜像；以下位置只是可审核样本。首轮可把岸面基准Y0暂设在-32附近作对照，最终高度须由覆岩和水文条件确定，不能在全世界硬套同一Y。

首样名义影响范围u约[-88,88]、v约[-40,40]、w约[-14,34]；边界不要求长方体轮廓。纵向范围包含池底以下与洞顶以上的围岩余量，不能理解为48格全空。

| 部位 | 局部位置或范围 | 空间关系 |
|---|---|---|
| 入口线索段 | u约-84..-60 | 稀疏细脉，视线尚看不到完整主壁 |
| 前部扩宽与小池 | 中心约(-46,-8) | 短暂停留，展示池缘与较弱矿化 |
| 主厅 | u约-34..34，v约-18..18 | 主壁在v正侧，较低岩台在v负侧 |
| 主池 | 中心约(-8,8) | 偏向主壁脚部，矿化带在附近入水 |
| 保留岩脊 | 主厅偏中后部 | 局部高3..6、厚3..6，遮挡支路而不把主厅切断 |
| 偏干支脉 | u约-12、v负侧 | 较窄的矿脉露头，较少植物和水 |
| 湿润侧厅/支池 | 中心约(54,22) | 小于主厅，轮廓与方向不对称 |
| 后部渐隐段 | u约68..88 | 矿脉逐渐变细，接回普通岩体/洞穴 |

主路径自然弯曲，不按固定房间模板拼接。玩家可以来自不同天然洞穴入口；首个样本只需证明从一处主要入口能获得清楚的观看顺序。首样建议保留1..2处明确连接，其他天然连接不强制全部封死。

## 5. 玩家进入与探索

1. 普通洞壁先出现1格宽、断续的浅色细脉和少量矿化点；几格到十余格内逐渐增强，外部还有普通围岩。
2. 通道发生一次自然转折/收窄，进入前部小扩宽。玩家可以看到浅池与主脉的部分走向，尚不能看穿整个矿区。
3. 进入主厅时，从距离主壁约18..30格的位置能看见斜向矿化带和池群整体关系。实际观察点不生成平台或提示，只作为验收相机。
4. 沿自然岩台可接近主壁；靠水一侧可看见同一矿化带继续延伸到池底。至少一种正常可走/涉浅水路径允许观察主要露头，不要求游过深池或精确跳跃。
5. 可选择偏干支脉或湿润侧厅，获得不同的采矿和空间视角。回望时主壁仍能提供方向感。

没有强制单行路线、恒宽步道、固定宝箱终点或关卡机关。深水/落差为可选探索，风险应能从地形看出；不新增隐形灼烧或毒气。

## 6. 主矿化岩壁：具体造型

### 轮廓

主壁较陡，但不是一块平直长方形屏幕。沿约40格的可见面保留2..3次起伏/凹口；局部岩台错开1..3格，模拟破碎与错动的观感。不移动现有世界岩层或模拟地质力学。

主矿化带在壁面上的倾斜约35..65度，位置和倾向随布局变化。标准样本可从局部(u=-18,w=0)附近斜向延伸到(u=8,w=22)附近，穿过围岩而不是沿同一个Y画水平白线。

### 浅色胶结与暗色碎块

主带常见可见宽度2..4格，局部交会/膨大到5..7格；只有少数短分支宽1..2格。带内用现有深色岩块构成1..3格的不规则残块，浅色方解石/石灰岩填在碎块之间，局部形成较连续的浅色脉。

主要特征是深色岩体被较浅矿化结构贯穿、胶结，不是完整白瀑布、不规则白墙纸或满墙钟乳石。大块碎岩与浅色填隙的关系应在正常18..30格观察距离仍能看出来。

### 三个层次

- 大形：一条具有清楚倾向的主带，跨越岩壁并延入水下。
- 中形：1..2条支脉、局部膨大和暗色残块，不重复规则间距。
- 小形：矿石露头和薄的边缘变化，数量服从主带而不是铺满每面墙。

这是地质关系的艺术化表达；方块颜色不能证明具体反应条件。方解石/石灰岩代表本设计的浅色碳酸盐充填，不把它们称为游戏中并不存在的石英矿脉块。

### 洞顶：矿化结构穿过的不对称破碎拱顶

洞顶与主壁、主裂隙使用同一份三维矿化结构，不作为另一个均匀撒装饰的平面。玩家从入口仰望，应看到主带沿主壁上升、穿过局部顶板，其他大部分仍为连续深色岩面。

**主体轮廓。** 主厅中央及偏主壁一侧的主要观察空间净高20..24格；对岸边缘缓降到约14..18格，连接段再收窄到7..12格。沿主轴只形成一处主要宽拱，前后逐渐降低，不每隔固定距离重复同样拱顶，也不做整片平顶。高点略偏一侧，让主壁具有更高的可见面。

**破碎层次。** 大形由不对称拱顶决定；中形保留2..3处和岩体相连的短岩肋、错台或斜向台阶，局部高差约1..3格。小形用有限表面凹凸和矿脉残块表现。台阶围绕局部岩层/裂隙关系变化，不绕洞厅形成等高环带。首样不增加浮空碎块或掉落方块机制；悬挑和残块应与顶板/侧壁有清楚的连接。

**顶部矿脉。** 主矿化面与曲面洞顶自然相交，形成1条可追踪主脉和少数短分支。顶面可见宽度通常1..3格，局部交会处膨大至4..5格；可连续看见约12..24格后被岩体遮住或向围岩中收细。长度是首样构图意向，不是每次固定截断。沿同一个三维矿化面放置，不能单独在顶部画一条与墙上不相接的白线，也不强行把倾斜矿脉拐成装饰直角。

**材料疏密。** 顶部代表性画面以约85%中性深色岩面、10%浅色矿化、5%矿化露头/湿润细节作为视觉起点；不是矿石概率。金属露头只在少数顶部脉段，不形成满顶彩色矿石。矿物仍向实心顶板内部延续，仰看能读出走向，但高处资源不是观察主景的必要门槛。

**湿润与植物。** 少量湿痕、地衣或短藤蔓集中在一两处湿岩缝，主脉及主要矿化壁上方保持清楚。首样最多以一处已有含水条件下的落水点作为次要构图，其他水声/滴水沿用已有系统；不为造景持续补水、不在全顶造瀑布、不用岩浆块或发光矿石照亮洞顶。大钟乳/石笋群不作为这一版的顶部主标志。

**顶板和水文。** 本场景仍是地下矿床，顶板外应有连续围岩。首样以洞顶最高处上方约6..10格连续岩体余量作为检查起点，最终厚度由原始地表、上覆洞穴和水体共同决定，不能把这个数字当成永不漏水/不被carver或结构切穿的保证。现有含水层曾在核心中央制造水层与隔层，必须在主壁纵剖和顶部断面中复查，避免用平顶隔板掩盖问题。若无法保住主景净空，需要调整局部密度/水文或候选高度，不用后期填块或关闭全世界含水层补救。

顶部相关形状和矿化字段属于原布局与密度/材质计算的延伸；不增加一个独立的洞顶管理器、每格气候查询或常驻tick。首样已按此方向生成；用户观看后认为拱顶辨识度不足，需进一步审核顶板构型，详见末节结果。

## 7. 池群与沉淀

| 池盆 | 首样意向 | 作用 |
|---|---|---|
| 前池 | 长12..16、宽6..9、深1..2 | 提前展示少量沉淀和较弱矿化 |
| 主池 | 长16..22、宽9..14、主要深1..3 | 作为主壁前景，局部池底可见主带延续 |
| 支池 | 长8..14、宽5..9 | 提供湿润侧厅变化；可以由种子取消 |

池盆边界不画完整椭圆光环。约1/3..1/2池缘可有明显浅色沉淀，其余为围岩、碎石或薄沉淀；局部岸沿厚1..2格，少数沉淀坎2..3格高，避免每池都有相同台阶。

相通的静水池应有一致水位；独立池盆可有1..3格高差，有流动连接时必须有实际可用的溢流路径。水道通常宽1..3格，沿局部低洼走，不做直角沟渠。较深点有自然浅岸供退回。

初次生成只放有限普通水，之后交给已有流体/热系统。池盆有真实盆底和边沿，无持续补水/回填/恒温。水中矿化结构可以继续到岸边岩体，不能只用水色表示“矿化”。

本场景不要求活跃热泉。若没有已存在且有效的热源，水按正常环境处理；不为好看加入永久蒸汽、无来源气泡或热量注入。

## 8. 材料、照明与装饰配比

首样视觉意向为约75%中性围岩与暗色残块、20%浅色矿化/沉淀结构、5%较强彩色矿化与植物点缀。此比例针对代表性画面，不是整矿区方块数量或矿石概率合同。

| 内容 | 处理方式 |
|---|---|
| 深板岩/石头 | 围岩主背景，保留较大连续安静面 |
| 凝灰岩 | 局部围岩变化，不能再包成统一外壳，也不宣称它必然是一种蚀变矿物 |
| 方解石/已有石灰岩 | 主带中的浅色充填和局部池缘，避免水平全环 |
| 现有矿石 | 分成局部矿化段和小团块，部分埋入围岩 |
| 藤蔓 | 集中在少量湿岩缝和水边，不形成满顶绿色帘幕；主壁可见面大部分留清楚 |
| 发光地衣 | 少量潮湿位置保留已有自然发光，不新增光源方块或发光矿物 |
| 岩浆块/熔岩 | 不作为本主题默认的橙色装饰层；既有内容需按实际地质/热条件局部保留，不能再以全区50..100次/区块来铺背景 |
| 颗粒与声音 | 首样不依赖常态白灰颗粒模拟蒸汽；保留正常水声、环境声，不新增循环效果或BE |
| 瓮/地牢/遗迹 | 仍属其他系统的偶然内容，不作为热液矿床识别特征 |

正常光照下不能要求无光洞穴像夜视截图一样明亮。允许玩家用现有照明观察；结构对比应在已有手持/放置照明下仍清楚。验收分别拍正常光照与夜视，夜视只辅助检查。

## 9. 矿石与采矿反馈

主矿化带使用当前已有的黄铁矿、铅、锌、银和少量铜等作为游戏表达，具体组合不声称是全部热液矿床的普遍地球化学规律。既有镍等背景资源不因本稿直接删除，是否参与主脉另行核对。

一处局部矿化团块以一种主要矿种为主，可有另一种伴生，避免每隔一格切换五六种矿石的彩色棋盘。黄铁矿可以作为常见线索，但不能全墙都变成可采矿石。

主带部分位置向实心围岩中继续约4..8格，主厅以外可逐渐变细。交会和膨大处允许更集中露头；不保证见到每一条白脉都必有贵金属。次级空间的矿化也与可见结构相关。

先以相同种子、相同热液包络和比较范围下的现有装饰方案测出各矿种总量B_i，再按地貌重分布。新样本的各矿种总量暂以B_i上下10%作为初始比较带，实际游戏平衡需另审；当前没有测出B_i，不能假填每处几组矿石或把相对指标写成现成产量。

不以减少全部feature次数来制造性能优势，也不因洞厅缩小而无说明地删掉原资源。外圈维持较稀疏线索，较集中资源主要埋在可解释的脉段附近。

## 10. 自然随机变化

不使用jigsaw或预制房间。布局由主裂隙、有界局部扩宽、池盆、矿化面和少量残留岩体组合。

| 保留的不变量 | 可以变化的内容 |
|---|---|
| 至少一处清楚可见的主矿化壁 | 主轴方向、镜像、壁的偏侧、主带倾向 |
| 有一个主要空间和能接近的浅岸 | 主厅长宽高、岩台起伏、局部凹口 |
| 主带从壁面延续到低处岩体 | 支脉数量、分叉位置、膨大段和矿种局部组合 |
| 默认有主池，水体状态符合流体规则 | 前池大小、支池取舍和少量高差 |
| 主要探索空间连通 | 连接段弯折、侧厅偏向、1..2处天然接口 |
| 整个已接受主体的群系归属一致 | 外围噪声轮廓、稀疏矿化与细节 |

不把所有随机范围都同时推到最大。首次只做一个标准样本，之后测试大小与干湿变化；罕见巨厅属于后续变体，不作为默认矿床。

出现密度与形状分开。固定样本不调世界稀有度；自动分布阶段先以当前稀疏候选作为比较基线，记录相同世界范围中每平方公里成功主体数、重叠率和资源总量。旧placement.chance=1只表示不额外随机拒绝候选，不能解释为每片群系必有主体，也不直接给出有效矿床密度。未测这些值前不承诺具体出现频率。

## 11. 群系与边缘

群系包络应覆盖主厅、池盆、矿化岩壁、残留岩体与周围岩层，并为quart混合预留空间。岩脊或柱子不挖空时仍属于热液，不能因此在地图上变成其他群系。

外围矿化强度可在约12..24格过渡带中逐渐减弱，细脉变细、减少，围岩恢复原样。这个强度是材质/细节权重，不等同于用最终离散群系ID硬切几何。空腔通过收窄、降低净高和少量天然连接回到普通洞穴。

不能只继续使用min(原洞穴密度,新洞厅密度)就宣称空间已受控：它会保留并接入原有大洞穴，实机已有这个问题。样本需要核对候选附近原始洞穴；必要时局部弱化原开挖场或在密度阶段保留所需岩体，并设置有限接口。具体局部组合与水文路由是待验证技术问题，不能把保留岩体画在示意里就当成已生成。

“每个成功接受的完整主体都满足本版构型”与“每一片原有热液群系碎片都有主体”是不同合同。正式自动分布若要求后者，必须使特殊群系归属和布局接受规则一致；保留独立气候碎片时无法保证。此艺术化设计不代替这项架构决定。

## 12. 生成职责与最小复杂度

| 阶段 | 职责 |
|---|---|
| 布局 | 一条约4段主轴、1个主要扩宽、1..2个次级扩宽、2..3个池盆、1条主矿化面与少量分支；种子决定有界参数 |
| 密度 | 形成主要洞腔、拱顶与必要保留岩体，在原版NOISE阶段接入；不在装饰后重挖 |
| 含水层/初始水 | 与实际洞腔及池盆一起测试，满足岸边可探索空间；不靠tick回填维持 |
| 材质与矿化 | 按主脉/破碎带/池缘字段放置现有岩石和矿石，跨区块连续 |
| 小feature | 使用布局区域约束分布，保留局部自然变化，避免随机大湖或全顶装饰盖住主景 |
| 完整验收 | 实际群系、空气/水、资源量、画面和FULL区块耗时 |

X/Z方向的主轴距离、洞底/顶投影、池盆及外围权重尽量缓存；斜向矿化面按坐标做简单运算，只有接近该面才进入局部矿石/残块判断。不在每个体素重新查询完整气候表或规划布局。

先复用已经能正常注册和运行的测试密度/群系接线做固定锚点样本。自动选址、全部矿床和火山不在首样中展开。不新增Mixin、ChunkGenerator、世界区域数据库、后台管理器或新方块/物品。

作者层应编辑少量可读参数：整体尺寸、主厅尺寸、主带倾向/宽度、池盆尺度、边缘变化和材料/资源预算。内部段坐标、散列盐、插值余量、缓存容量由实现推导，不要求作者同时维护多套出现频率。

当前未测性能，不能承诺“尺寸更小一定更快”或“增加几处侧厅零成本”。候选和几何节点须有界，普通区域快速排除，正式接线要保留已有群系列缓存。

## 14. 验收标准

### 构型与地质表达

- 隐藏F3群系名，正常照明下从主入口的代表视角可同时认出主矿化带和池群关系。
- 主带在壁面、低处/水下露头和一处支脉有可追踪的连续关系；不是只贴一张好看的白色墙。
- 仰看时能追踪主带进入顶部的一段，顶板高低有主次且大部分岩面安静；无满顶均匀藤蔓/岩浆块、完整等高白环或无连接浮空块。
- 深色碎块、浅色胶结与局部金属露头至少有两级可见尺度，近看有细节、退远仍有主倾向。
- 不出现大面积同高白环、满顶藤蔓和到处等密矿石。普通岩面和主矿化面有明确差别。

### 尺度与可玩性

- 主厅按60..80×30..42与主要净高18..26的设计区间审视实际方块，记录中央与代表断面；不以连入其他天然洞穴后的巨大包围盒充数。
- 主入口至主要观察位置有实际可走/涉浅水路径，不要求恒宽、恒干或完全无植物。
- 局部深水、支脉和落差可选；从侧厅返回能用主壁定位。
- 核心必要路径和主景空间连通，不以极少孤立单格空气作为全局美术失败，也不以99.99%连通掩盖关键入口被堵。

### 群系、水与资源

- 已接受主体的露头、围岩、残块和池盆都属于热液包络。记录quart和玩家方块位置查询，不用单张Y切片代替三维覆盖。
- 实际含水层不能把主要视景空间分成上下两层水洞；主壁的中央观察断面达到本稿主要净高目标。池水交给现有物理，后续至少做原600秒观察基线；若此前系统合同要求tick数，沿用原合同。
- 露头指向岩体中的矿化，资源总量与分布分别核对；不能以覆盖率增加或采集量翻倍冒充辨识度提高。

### 性能与记忆

- 对同种子、同包络/资源预算的完整区块，比较普通区域与矿区的均值、P95、分配量、缓存上界和后续tick行为。没有通过前不写“最优性能”。
- 先同条件画面对照普通洞穴，确认观察者能描述斜向含矿岩壁和池群。再检查从支路回望是否可辨位置，采矿是否与线索对应。
- 玩家记忆是待验证结果，不靠评分、承诺或单张夜视截图替代。首轮没有外部玩家测试授权，不擅自联系他人。

## 15. 首轮实施顺序与阻塞项

1. 固定现有测试种子/位置，先出主体与主壁的无装饰样本，验证构图与原洞穴关系。
2. 增加矿化面、残块与水下延续，不先铺全域矿石；检查正常照明与夜视。
3. 接入池盆、含水层和普通流体，解决实际净空；若水文不能稳定满足，不用无限补水或关闭全世界含水层掩盖。
4. 按布局接回现有小feature，核对资源和装饰疏密，拍相同相机对照。
5. 测多个方向、尺寸、干湿变化；通过后再决定自动分布与严格归属接线，并扩大到其他矿床。

当前确定的是艺术化构型与首样内容。未解决并需单独验证的是：局部原洞穴组合、含水层净空、天然洞口/结构相交、动态群系与布局同步、精确资源预算和FULL区块性能。本稿不将这些写成已实现保证。
