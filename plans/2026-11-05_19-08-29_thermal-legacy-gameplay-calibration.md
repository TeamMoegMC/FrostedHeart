# 旧玩法生存与资源体验的简洁数值定标

- Authors: `Codex; OpenAI GPT-6; primary engineering agent`
- Status: `completed; selected normal-difficulty survival/wind targets met, broader parity remains separately scoped`
- Scope: 当前五部位人体、热食倍率边界、既有数值测试；不重建旧模拟器或修改世界拓扑/调度
- Related: [当前测量](../docs/climate/thermal-gameplay-balance.md)、[旧玩法基准](../docs/climate/thermal-legacy-gameplay-parity.md)

## Goal

保留新传热机制，以普通难度下的失温危险、有限食物生存时间、衣物升级收益和取暖恢复接近旧玩法；不追求旧HUD或每一点温度完全相同。极端过载继续以性能为主。

## Verified Current State

- 已有真实有限食物参照：−50/−80°C裸体旧身体约22:18/14:12死亡；羊毛−50°C一小时食物10，−80°C约28:14食物耗尽。
- 新身体把`temperatureChangeRate`用于全身积分与御寒消耗，旧普通身体不使用此倍率，整合包0.5因此额外减半。仅改速度不能修复热量平衡。
- 当前世界供暖功率、衣物定义、单一五部位积分器、真实暴露与辐射W分离均可保留。

## Implementation

1. 用已有有效49组曲线及真实衣物数据做有限参数拟合，数学探索脚本放ignored `build/`，不为拟合增设正式模式/参数框架。
2. 普通身体按实际经过tick与单一生理时间尺度推进，去掉`temperatureChangeRate`乘法；该配置保留旧热食/冷食及对应提示作用，修改配置说明。
3. 优先只改现有空气交换、代谢/御寒功率及资源换算常数。禁止按具体温度场景硬编码特殊补偿，禁止以调整HUD代替玩法变化。
   首轮统一验证确认无风目标已满足、强风仍偏弱，补充单个`WIND_EXCHANGE_MULTIPLIER=0.045`：按强迫对流超过自然对流的比例连续作用，不增加状态、查询或特定场景条件。
4. 更新现有测量中对速度的假设及资源计量，新增必要的倍率独立性回归。完成所有实现和所有权/量纲/伤害闭合复查，再统一Forge验证。

## Validation

- 裸体−50/−80°C的有限食物死亡时间力争落在旧参照±25%，保持旧危险排序；羊毛−50°C一小时仍存活且耗食接近旧10，−80°C须有明确资源压力。
- 同时看无食物和持续食物的身体诊断、熊皮升级、近火回暖、真实篝火/衣物/暴露伤害及温泉接触。固定回放不是有限食物验收，入口完成不是数值通过。
- 只运行重点Forge组，不跑JUnit或百人矩阵；失败日志保留，只在实际发现问题时重测相关范围。
