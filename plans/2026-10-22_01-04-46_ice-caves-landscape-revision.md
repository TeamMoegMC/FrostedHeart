## 已确认目标

| 项目 | 用户要求 |
|---|---|
| A 覆盖 | 洞穴约 **80% 面积**被冰或薄冰覆盖，包含沿表面的层状覆冰；**高墙覆冰是明确目标**，不能只满足地面、洞顶 |
| A.a 团状冰 | 岩壁上嵌入直径 **5～10 格**的大块团状冰；约 **50% 概率**采用其他类型的冰 |
| A 补充：条带 | 团状冰以外，洞壁增加**少量不同冰种的条带点缀**；如果容易实现，优先呈纵向。数量、宽度没有指定，不套用团状冰的 50% |
| A.b 冰柱 | 优先沿用大型滴水石塑形，形成上下呼应的粗大冰笋、冰钟乳；**允许部分不贯通**，可有相连冰柱，零散镶嵌冰晶。此项经补充确认，替代早期全部贯通的要求 |
| A.c 陷阱 | 洞底附近挖出 **3～12 格深**的空腔，薄冰封顶；**20% 的空腔整个填满普通水**，其余为空气。已向用户确认是全腔填水，不是底部积水 |
| A.d 实体冰刺 | 接受**原版浮冰尖塔外形与少量雪块底座**；要求**分布稀疏、体积较小**，具体尺寸与频率待样本调试；不以修改功能冰锥属性来代替 |
| B 冰湖 | 湖的整个上表面覆冰；约 **80% 薄冰，20% 普通冰或浮冰** |
| C 功能冰锥 | 仍为顶部下垂；生成更密，更偏向冰块下方；冰锥本身属性不变 |
| D 晶体 | 可生成在上述大块冰、实体冰刺和冰柱内部，冰柱上也有零散镶嵌 |
| E 矿物 | 生成量最好不超过热液的 **2 倍**；软锰矿单条矿脉规模缩至当前 **70%**，**不增加次数补偿，总量也降低** |
| F 温泉 | 暂且不变，包括既有入口、近处和内部晶体提示；已有自然生成和回暖待验收项继续保留 |
| G 空间差异 | 小洞道以覆冰和下垂冰锥为主；大冰厅呈现冰柱、实体冰刺、冰晶等特殊景观 |

## 比例与形态的建议解释

以下是实施建议，尚非额外的用户确认参数；若要改变上述目标，应先回到讨论。

- **80% 覆盖**：按洞底、岩壁、洞顶的自然可见表面理解，不是整个地下体积或每次尝试的成功概率。三类表面分别报告，不能只铺满地面；矿石表面不能从统计中排除以虚增覆盖。湖面另外验收全覆盖。温泉池与干岸按 F 保留，并报告其范围。
- **层状覆冰**：指顺应地形的冰壳及厚薄变化，不等于所有位置都用 `layered_thin_ice`。一般通路和墙顶可用稳定冰体；脆弱薄冰集中用于湖面、陷阱及少量合适地面。
- **团状冰的 50%**：建议按每团抽选材质族，约一半以普通冰为主，另一半从浮冰、蓝冰、FH 坚冰等已存在的实体冰中选择；团内连贯过渡，避免逐格独立随机的杂色拼盘。具体权重未定，不能把所有其他冰都等概率视为已批准。
- **洞壁条带**：建议在主体覆冰中穿插少量浮冰、蓝冰或 FH 坚冰的纵向色带，宽窄有变化，与团块共存。它是冰壁内部的材质变化，不另算覆冰面积，也不要求条带一定贯通洞底和洞顶；纵向倾向服从“容易实现、原版复用优先”，仍以样本观感决定。
- **大型冰体**：沿实际洞底和洞顶塑形，根部嵌入地形，形成粗细变化、上下呼应的冰笋与冰钟乳；允许部分连接，不强制补齐每根柱体。仅在有足够空间的冰厅生成。
- **小型实体冰刺**：采用向上渐细的原版浮冰尖塔轮廓，保留少量雪质底座，缩小体积并稀疏分布。此要求替代此前实体冰刺“成簇为主”的建议；C 的顶部功能冰锥仍可更密，两者分别调节。
- **陷阱**：建议深度从薄冰下第一格算到坑底上方，20% 按整座陷阱抽选，不能每格独立抽水。宽度、频率待样本调试；按 G 优先放冰厅。检查岩体厚度、下层洞穴和水体，避免生成后直接漏水或把干坑灌满。
- **湖面 20% 稳定冰**：普通冰和浮冰合计约 20%，建议形成短带或片区，薄冰仍占主体；不承诺每个湖都存在完整安全通路。处理普通地下湖，温泉不覆冰。
- **晶体内部生成**：荧石晶体是整方块，可直接替换冰体。现有冰晶是附着式晶簇，应在冰体内留有支撑的小空腔中放置；部分靠近外表面或由透明冰包围。需要实际检查可见性，不能承诺透过所有冰材质都能看见。延续荧石附近冰晶和温泉提示，荧石仍属于 glowstone 体系。
- **矿量 2 倍**：建议逐矿种比较等体积、同高度范围、多种子的最终生成方块总量，计入双方全局矿脉和热液晶洞；不是所有矿种加总平均，也不是只比较 count。没有热液对照的软锰矿按专属规则处理。保留资源较丰富、银相对少量的方向，2 倍是上限目标，不必把每种矿都调到上限。
- **软锰矿 70%**：可先把 `OreConfiguration.size` 从 `30→21`、`8→6`（取整初值），不提高尝试次数补量。size 不是直径或实际方块数，总量不会必然正好乘 0.7。保留宽厅优先的空间倾向，旧“最终总量为黄铁矿 1/2、1/4”的承诺不再硬性维持；也不以新数值宣称精确达到 35%、17.5%。

## 原版复用优先（2026-10-22 补充）

用户明确要求：**能直接照搬就优先照搬；能复用但效果存在偏差时，先说明偏差，由用户决定是否接受。** 因此下文步骤表达目标与依赖，不表示所有内容都要新写生成器。顺序为已有生成器的数据配置、保留原版算法的最小适配、最后才考虑独立算法；不能静默牺牲 A～G 目标。

覆冰补充取舍：用户不接受仅用繁茂洞穴算法而遗漏高墙。优先通过必要适配或自定义表面处理达到墙、顶、地面的整体覆冰；只有自行实现确实很困难或无法达到所需效果时，才考虑直接使用繁茂洞穴式覆盖作为退路，并明确说明剩余差距。可以复用其局部找表面等逻辑，但不能把“原版复用优先”理解成自动降低覆盖目标。

本轮只读核对了本地 Minecraft 1.20.1 客户端内置 JSON、Forge 47.3.0 映射后的原版实现，以及从 Mojang 官方分发获取的 26.2 客户端内置 JSON。临时反编译只用于阅读，没有构建或改动项目。

| 目标 / 参考 | 可以复用什么 | 原样复用的偏差与限制 |
|---|---|---|
| 地面、洞顶覆冰 / 繁茂洞穴 | `vegetation_patch` 的 `ground_state`、深度、半径、替换标签和附属 feature 都可配置；逐列在限定高度内寻找真实表面。`moss_patch` 与 `moss_patch_ceiling` 可改为冰 | 仅支持 floor / ceiling，不能直接涂满竖直高墙；用户已明确不接受这一缺失作为默认效果。优先补足高墙处理，原样使用仅作困难时的备选；斑块也不保证最终覆盖恰为 80% |
| 连续冰质分区 / 硫磺洞穴 | 26.2 `overworld.json` 用 `sulfur_cave_gradient` 三维噪声和群系条件选择硫磺、朱砂等材质；池、尖锥是另行配置的 feature | 26.2 新增 `noise_threshold.is_3d`，1.20.1 不能原样导入这段 JSON。可借鉴连续材质分布，但是否只需适配表面规则、以及雕刻器后新增表面的覆盖，要再核实 |

| 大柱与粗冰刺 / 滴水石洞穴 | `large_dripstone` 已有洞底/洞顶扫描、随洞高约束半径、嵌入岩体与粗细塑形，优先沿用这套几何算法 | 输出材料写死为滴水石，并有滴水石基底判定，需适配为冰。用户已接受部分上下不相连的冰笋、冰钟乳，因此不为每根追加强制贯通逻辑 |
| 5～10 格壁内团状冰 / 原版团块或矿脉 | `block_blob` 可配材料，`ore` 可配冰质输出与宿主 | 前者是向下找地面的若干小球，尺寸未开放，不能直接当壁内大冰团；后者可形成埋藏冰脉，但不能保证圆团、5～10 格直径和洞壁露出。形态偏差接受前不自动替代 A.a |

条带补充核对：1.20.1 `SurfaceRules.NoiseThresholdConditionSource` 的条件继承 `LazyXZCondition`，实际采样为 `NormalNoise.getValue(blockX, 0, blockZ)`。因此原版已有可沿高度保持一致的二维噪声分区，可优先尝试用较窄的噪声取值带选择其他冰种，得到偏纵向的材质条带；不必为了这个方向偏好直接移植 26.2 的三维条件。其偏差是条带可能较直、延伸很长，甚至在同一水平位置的不同洞层重复，倾斜洞壁上的投影也会变化；不保证天然形成弯曲、分叉和渐消。此结论只验证了材质选择原理：实际表面规则作用范围、后续雕刻与覆冰覆盖顺序仍需核对，不能宣称只改一条 JSON 就能完成所有洞壁。优先随既定覆冰流程复用这种取材方式，不为条带另建复杂生成系统。

## 建议实施顺序与验收

1. **先覆冰和湖面**：沿真实地形处理墙、顶、地面，采用空间上连续的覆盖分布；覆盖矿石时优先在外侧包冰而保留矿体，狭窄处保持通行。明确每区块的处理职责和邻域范围，跨边界不留网格缺口，不依赖无限扫描或强制远处区块生成。
2. **再大冰体和陷阱**：团状冰、大型冰笋/冰钟乳与部分相连柱体、小而稀疏的实体冰刺、3～12 格陷阱，先检查完整体积再生成。宏观冰体完成后再放晶体和下垂冰锥，保证冰质支撑偏好生效；实际 feature 阶段需重新核对温泉、矿物及其他装饰顺序。
3. **最后调资源**：按最终地形重新采样。除总量外检查可见露矿面和连续矿片，不能为了遮住过密矿物而只把它们埋进冰里。软锰矿不做补量；温泉暂不调参。
4. **验收独立记录**：洞底/高墙/洞顶冰覆盖、湖面全覆盖及约 80:20 材质、大厅与窄道差别、大冰体根部嵌入与上下呼应、小冰刺体积及稀疏程度、晶体可见性、干/湿陷阱比例与破裂结果、矿量逐项上限、区块边界与生成耗时。先看多种子正常预设新洞穴截图，再结合统计判断，不能用固定群系总冰块数替代景观验收。
5. **运行后仍需观察**：大片冰与薄冰进入现有 FH 相变后，形态和湖面比例是否持续合理；不为保住世界生成比例自动修改温度或薄冰行为。实施后分别更新 FH/TWR 当前行为文档和开发日记。
