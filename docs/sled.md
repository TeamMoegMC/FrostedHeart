# 雪橇地面运动过渡

状态：已按源码核对。最后核对日期：2026-11-13。
范围：`SledEntity`、`SledGroundTransition`、`FHConfig.Common.sledGroundTransitionTicks`。

通用配置 `Sled.sledGroundTransitionTicks` 默认 10 tick（0.5 秒），范围 0 至 2147483647；0 立即切换。替代旧 `sledSnowGraceTicks`，旧键不再影响行为，需按新键重新配置。COMMON 配置不自动同步，驾驶客户端需配置一致。

接地时摩擦速度保留系数和前进加速度在指定 tick 数内线性过渡到目标。目标在过渡期间改变时，从当前值重新过渡；持续变化的地形参数会持续跟随目标。雪地基础速度保留系数为 0.97，前进加速度为 0.015（有狼 0.017），非雪地前进加速度约 0.037。俯仰角仍参与目标摩擦计算。

实际地面类型、粒子、转向制动、碰撞和重力即时处理。入水或离地立即停止过渡，重新接地从实际地面参数开始；空中和水中仍使用原有物理。运行参数不持久化。速度按当前水平速度乘过渡系数再叠加输入加速度计算，不对碰撞后的速度做插值。
