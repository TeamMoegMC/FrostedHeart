# 流体运输

- Status: 已实装
- Last verified: 2026-11-27
- Scope: 《冬季救援》T2 流体运输研究、实验台和旧蒸汽动力前置
- Code anchors: `the_winter_rescue:fluid_transport`、`frostedresearch:water_collected`、`item.filled_container`、`ExperimentConditions`、`LegacyResearchBridge`

在世界中用桶或陶桶成功盛取普通水时，每次有 5% 的基础概率获得想法。队伍掌握齿轮设计时加 20 个百分点，合计 25%。也可以在绘图台联络三份物品观察，分别是有内容的液体容器或桶、小齿轮和铜板。旧容器观察缺少内容记录时可重新检视。队伍学会想法并掌握齿轮设计后开题。

1. 完成 `frostedresearch:drafting/four_blade_pump` 尺规绘图。图纸标出轴心和右侧桨叶的 R20 圆弧圆心（24, 0）mm。用圆规依次点击圆心和圆周落笔。
2. 完成 `frostedresearch:nesting_pack`，把全部零件装进槽内。
3. 在同一间封闭实验室内放置 `create:hand_crank` 与至少一格 `minecraft:water`，用实验台消耗 3 铜板、1 铜锭及 1 个任意普通齿轮（青铜、铸铁或钢）。实验时长 100 游戏刻，20 TPS 时为 5 秒。曲柄和水保留在房间内。

在绘图台定稿，队伍获得管道、机械泵和流体储罐三项设计。管道设计覆盖横竖两种工作台配方。旧研究的三个配方效果按 [旧档映射](../research/legacy-content-disposition.md) 逐项承接。新版研究的正式完成及有效成果满足 `steam_powerd` 的 `fluid_transport` 前置。
