# World Generation

This directory documents implemented terrain and resource generation used by the companion pack. Source code and the pack's `kubejs/data/` files are authoritative.

Read [Ice Caves](ice-caves.md) for the new cave features and provisional spawn budgets. For the wider pack's mineral comparison, see [Mineral Generation Estimates](../worldgen-mineral-generation-estimate.md).

Changes to feature types belong in FrostedHeart; placement, frequencies, and biome attachment belong in TheWinterRescue. Validate both repositories after changing a data reference.
